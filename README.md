# ESI Colombia - Educación Sexual Integral

Este proyecto es una página web educativa dirigida a niños y jóvenes en Colombia.

Su objetivo es brindar información clara, segura y accesible sobre:
- El conocimiento del cuerpo
- Los límites personales y el consentimiento
- La protección y el autocuidado
- Líneas de ayuda y apoyo emocional

## Estética
El diseño está inspirado en ilustraciones infantiles y editoriales modernas, con colores suaves, formas orgánicas y una navegación simple.

## Propósito narrativo
Crear un espacio digital seguro donde aprender sobre sexualidad desde el respeto, la información confiable y el bienestar emocional.

## Accesibilidad
La página es completamente responsive (celular, tablet y computador) y de navegación simple para facilitar su uso.
